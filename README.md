# PRML Lab

A math-first, experiment-driven exploration of _Pattern Recognition and Machine Learning_ (Bishop).

This repo is structured as a series of **chapter-wise experiments**, where each concept is derived from theory, and visualized for intuition.

---

## Chapters

| Chapter                              | Topic                        | Experiments                                                                        |
| ------------------------------------ | ---------------------------- | ---------------------------------------------------------------------------------- |
| [Chapter 03](./chapter_03/README.md) | Linear Models for Regression | Basis functions, least squares, bias-variance, regularization, Bayesian regression |

---

## Philosophy

- Focus on **math**
- Use **controlled synthetic data**
- Learn via **experiments and plots**

---

## Stack

- NumPy (core computation)
- Matplotlib (visualization)

---

## How to Use

Each chapter contains:

- independent experiments with results / plots.
- a README explaining theory + observations.

Start from Chapter 3 and follow experiments sequentially.
